# MowgliNext Lab

This fork is the shared, experimental workspace for the YardForce SA650ECO
(`automower3`) running MowgliNext on a Raspberry Pi 5.

It is intentionally kept as a fork of `mowglinext/mowglinext` so that a
validated, minimal change can be proposed upstream as a normal pull request.
Lab-only notes and tools live under `docs/lab/` and `tools/lab/`.

Start with:

- [Current field status](docs/lab/STATUS.md)
- [Collaboration and safety workflow](docs/lab/WORKFLOW.md)
- [Build and deployment notes](docs/lab/BUILD.md)

Do not treat an experiment in this fork as production-ready merely because it
works once in the field. Keep every live test supervised, blade-off, bounded,
and recorded in the status log.
